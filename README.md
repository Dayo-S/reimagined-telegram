# Banned Book Club

One-page site about a student book club that reads banned books.

## Local development

1. Ensure you have Python 3 installed (or any simple HTTP server).
2. Open a terminal in this directory.
3. Run: `python -m http.server 8000`
4. Open `http://localhost:8000` in your browser.

No npm install, no CDNs, no build step. Edit `index.html`, `style.css`, or `script.js` and refresh to see changes.

## Project constraints (see AGENTS.md)

- Only `index.html`, `style.css`, `script.js` — no dependencies or CDN.
- Responsive at narrow and wide browser widths.
- Keyboard accessible.
- All work stays inside this project.
- Serve only on localhost.
